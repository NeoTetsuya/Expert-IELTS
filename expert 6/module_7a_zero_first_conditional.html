Zero & First Conditional

Master general truths & rules with Zero Conditional, future possibilities with First Conditional, comma rules, and key connectors (when, provided that, even if, unless)!

If / When

A. Zero Conditional (Rules, Truths & General Facts)

Used to state things that are always true, scientific facts, or strict rules.

Function ⚙️

General Truths & Rules

Expresses a cause-and-effect relationship that is always true or automatic.

👉 "If you go to China, you need a visa."

(= An official travel requirement/rule)

👉 "People often experience difficulties when they travel."

(= Something that generally happens all the time)

Formula 📐

Grammar Structure

Both clauses use the Present Simple tense!

If / When + Present Simple, Subject + Present Simple

Note: You can swap if with when in zero conditional sentences without changing the fundamental meaning!

⚡ Zero Conditional Formula Summary

If-Clause First (Requires Comma)
If + Present Simple, Present Simple

✓ If you go to China, you need a visa.

Main Clause First (No Comma)
Present Simple + if / when + Present Simple

✓ People experience difficulties when they travel.

Future Possibility

B. First Conditional (Future Possibility)

Used to talk about specific things that might happen in the future.

Positive Outcome 🔮

Possible Real Future Situation

Predicts a realistic outcome if a future condition is fulfilled.

👉 "If I have time in the summer, I'll go to the coast."

(= Present condition → Possible future result)

Negative / Warning ⚠️

If... don't / won't

Expresses negative conditions or warnings about future consequences.

👉 "If you don't visit the pyramids on your trip, you'll regret it."

⚡ First Conditional Formula & Clause Order

Clause Order Condition Clause (If) Punctuation Main Result Clause
If Clause First If + Present Simple COMMA (,) Subject + will / 'll + infinitive
Main Clause First Subject + will + infinitive NO COMMA if + Present Simple
🔗

C & D. Punctuation Rules & Conditional Words

Comma rules and using when, provided that, even if, and unless.

✏️ C. Punctuation Rules in Conditionals

1. If clause in FIRST half = USE COMMA (,)

Must put a comma between the two clauses:

"If we hurry, we will be able to make the flight."

2. If clause in SECOND half = NO COMMA

Do NOT use a comma when main clause comes first:

"We will be able to make the flight if we hurry."

1. WHEN

Things happening all the time

Used only in zero and first conditionals.

👉 "The science class is better when we do practical work."

👉 "When scientists begin new projects, they usually have clear aims."

2. PROVIDED THAT

Desired Outcomes ONLY

Stresses something will happen only if another thing happens. Used ONLY for things we WANT to happen!

✅ "Provided that the vote is positive, the new airport will be built."

❌ Incorrect: Provided that time runs out, the forest cannot be saved.

3. EVEN IF

Outcome remains true regardless

Emphasizes that something will STILL be true. Used in any conditional form.

👉 "The area will benefit, even if only a few tourists come."

👉 "Even if we cut down on flights, air travel will cause pollution."

4. UNLESS (= IF NOT)

Stronger warning tone

Means 'if not'. Used in zero and first conditionals only.

👉 "Unless we build more hotels, there will be nowhere for tourists to stay."

(= If we don't build more hotels...)
